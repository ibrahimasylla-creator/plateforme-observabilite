# ObservaLab — Frontend React (Design Clair & Épuré)

Application web de gestion de commandes conçue pour évaluer et comparer les architectures d'observabilité **ELK** et **OpenSearch** couplées à **Prometheus** et **OpenTelemetry**.

## Lancement rapide
```bash
npm install
npm run dev
```
Accédez ensuite à `http://localhost:5173`.
